================================================================================
DELIVERABLES
================================================================================

1. ReasoningStep (Atomic reasoning units)
   ─────────────────────────────────────
   Purpose: Represent a single action/outcome pair in execution trace
   
   Attributes:
   - step_number: Position in sequence (1-indexed)
   - action: Name of action (e.g., "run_algorithm", "compute_metric")
   - result: Outcome description (e.g., "DAG estimated in 0.43s")
   - metadata: Dict of context properties
   
   Methods:
   - to_dict(): JSON-serializable dict representation
   - to_string(): Human-readable formatted string

2. ChainOfThoughtTracer (Full reasoning trace)
   ────────────────────────────────────────────
   Purpose: Log all steps in a benchmark run with full context
   
   Attributes:
   - method_name: Causal discovery method (e.g., "PC", "GES")
   - simulator_name: Dataset simulator (e.g., "ErdosRenyi")
   - run_id: Unique run identifier
   - steps: List of ReasoningStep objects (built incrementally)
   
   Methods:
   - add_step(action, result, metadata): Append step to trace
   - get_trace_string(): Human-readable formatted trace
   - to_dict(): Structure for JSON export
   - to_json(): Serialized JSON string

3. Explanation (Natural language narration)
   ────────────────────────────────────────
   Purpose: Combine trace + semantic + metrics into narrative explanation
   
   Attributes:
   - run_id: Benchmark run identifier
   - method_name: Algorithm name
   - composite_score: Final score [0, 1]
   - semantic_context: Domain/noise/size constraints applied
   - fired_rules: List of semantic rules that adjusted scoring
   - component_scores: Individual metric scores
   - tracer: Optional ChainOfThoughtTracer reference
   
   Methods:
   - to_narrative(): Generate paragraph explanation
   - to_dict(): JSON-serializable representation

================================================================================
EXAMPLE USAGE
================================================================================

from pgmpy.benchmark import (
    BenchmarkRunner,
    ChainOfThoughtTracer,
    Explanation,
    ErdosRenyiSimulator,
    SemanticContext,
)

# 1. Create tracer
tracer = ChainOfThoughtTracer(
    method_name="PC",
    simulator_name="ErdosRenyi",
    run_id="run_001",
)

# 2. Add steps as benchmark executes
tracer.add_step("run_algorithm", "Estimating DAG...", {})
tracer.add_step("compute_metric", "SHD = 3", {"metric": "shd"})
tracer.add_step("compute_metric", "F1 = 0.82", {"metric": "f1"})
tracer.add_step("interpretation", "Good performance", {})

# 3. Get human-readable trace
print(tracer.get_trace_string())
# ======================================================================
# Chain-of-Thought Trace: PC on ErdosRenyi
# Run ID: run_001
# ======================================================================
# [Step 1] RUN_ALGORITHM: Estimating DAG...
# [Step 2] COMPUTE_METRIC: SHD = 3
# [Step 3] COMPUTE_METRIC: F1 = 0.82
# [Step 4] INTERPRETATION: Good performance
# ======================================================================
# Total steps: 4

# 4. Create explanation
explanation = Explanation(
    run_id="run_001",
    method_name="PC",
    composite_score=0.82,
    semantic_context={"domain": "biological", "noise_level": "high"},
    fired_rules=["high_noise_robustness"],
    component_scores={"shd": 0.80, "f1": 0.82},
    tracer=tracer,
)

# 5. Generate narrative
print(explanation.to_narrative())
# Method PC achieved good performance (composite score: 0.820) on biological 
# domain data with high noise level. Component scores: shd=0.800, f1=0.820. 
# Scoring adjusted by rules: high_noise_robustness.
